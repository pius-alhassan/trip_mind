# Contributing to Trip Mind 🧠

Welcome! 👋  
Thank you for helping build our MSc Intelligent Decision Support System project — *Trip Mind*.  
This guide explains how to contribute safely and effectively.

---

## 🧩 Project Structure
- `main` → stable release branch  
- `iterations` → development branch (integration happens here)  
- `feature/<your-name>-<task>` → your personal working branch  

Example:  
`iteration/fatma-ethics` or `feature/pius-recommender`

---

## 🧰 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/<org-or-username>/Trip-Mind.git
   cd Trip-Mind

## 🧪 Making Changes

1. Write clear, commented, and modular code.

2. Use docstrings for functions.

3. Commit small, meaningful changes:
    - git add .
    - git commit -m "Added EDA visualization for user reviews"
    - git push origin iteration/yourname-task


## 🔁 Submitting Your Work

1. Go to GitHub → open a Pull Request into iterations.

2. Title it clearly (e.g., “Added data preprocessing script”).

3. Wait for review — Pius (Lead Dev) will help correct and merge.

4. You’ll still receive authorship credit, even after code refactoring.

## 💬 Questions?

<p> If you’re unsure about anything, ask in our team group chat or tag @Pius in your PR.
We’d rather guide you than fix broken code later 😉 </p>
